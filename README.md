 Food Delivery Website(guided project)
A fully responsive food delivery website built with vanilla HTML, CSS, and JavaScript featuring a functional shopping cart, smooth UI interactions, and a modern Flexbox layout.


 Features

Responsive Design — Looks great on all screen sizes: mobile, tablet, and desktop
Add to Cart — Fully functional shopping cart with dynamic item management
Interactive UI — Smooth transitions and hover effects for a polished user experience
Modern Layout — Clean, organized design using CSS Flexbox


 Tech Stack
TechnologyUsageHTML5Semantic content structureCSS3Styling, Flexbox layout, transitionsJavaScriptCart logic, interactivity, dynamic content

 How the Cart Works

Browse food items on the menu
Click Add to Cart on any item
The cart updates dynamically — no page reload needed
Review your order in the cart panel before checkout
