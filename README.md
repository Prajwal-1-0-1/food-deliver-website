Food Delivery Website (Guided Project)

A fully responsive food delivery website built with vanilla HTML, CSS, and JavaScript featuring a functional shopping cart, smooth UI interactions, and a modern Flexbox layout.

Features
Responsive Design

Looks great on all screen sizes: mobile, tablet, and desktop.

Add to Cart

Fully functional shopping cart with dynamic item management.

Interactive UI

Smooth transitions and hover effects for a polished user experience.

Modern Layout

Clean, organized design using CSS Flexbox.

Tech Stack
Technology	Usage
HTML5	Semantic content structure
CSS3	Styling, Flexbox layout, transitions
JavaScript	Cart logic, interactivity, dynamic content
Project Structure
food-delivery-website/

    └── images/       # Food images and icons
Getting Started

No build tools or dependencies required — just open and run.

1. Clone the Repository
git clone https://github.com/your-username/food-delivery-website.git
2. Navigate into the Project Folder
cd food-delivery-website
3. Open in Your Browser
open index.html

Or simply double-click index.html in your file explorer.

How the Cart Works
Browse food items on the menu.
Click Add to Cart on any item.
The cart updates dynamically — no page reload needed.
Review your order in the cart panel before checkout.
